# Языковой тренажёр
Демо-сервис, созданный для ежедневной тренировки во время изучения иностранных языков. Сервис даёт возможность повторять лексику на трёх языках, предлагая варианты её использования и позволяя следить за прогрессом нескольких пользователей одновременно. 

## Функционал сервиса:
* выбирайте язык и тему для изучения и повторения;
* система языковых карточек – вводите перевод слова и сразу проверяйте корректность ответа;
* следите за своим прогрессом – программа считает количество данных и правильных ответов;
* просите подсказку, если возникают сложности;
* смотрите пример использования слова прямо во время тренировки.

## Доступные языки:
* Английский язык;
* Французский язык;
* Японский язык (на данный момент поддерживается только система письменности романзи!).

## Темы для изучения:
* еда;
* животные;
* предметы;
* глаголы;
* транспорт;
* места.

## Примеры карточек

| Слово    | Перевод  | Пример использования     | Подсказка           | Тема      | Язык |
|----------|----------|--------------------------|---------------------|-----------|------|
| carrot   | морковка | The rabbit ate a carrot. | оранжевый корнеплод | ЕДА       | EN   |
| écouter  | слушать  | J’écoute la musique.     | воспринимать звук   | ГЛАГОЛ    | FR   |
| densha   | поезд    | Densha ga kimasu.        | ездит по рельсам    | ТРАНСПОРТ | JP   |
